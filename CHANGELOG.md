# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project aims to follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Package skeleton `src/volforecast` with shared contracts and a uv lockfile (foundation commit).
- `Makefile` with setup, lint, format, typecheck, test, coverage, data, stack and Helm targets.
- Pre-commit configuration (hygiene hooks, ruff, mypy, gitleaks, nbstripout) and `.editorconfig`.
- GitHub Actions CI (lint, typecheck, test with coverage, security, Helm validation) and Dependabot configuration.
- Documentation: `docs/architecture.md`, `docs/execution_plan.md`, and architecture decision records 0001-0007, 0009 and 0010.

### Changed

- `README.md` rewritten for the refinement phase, with a results section that is generated by `make report`.
- Legacy code moved to `legacy/` (tag `v0-legacy`) and excluded from lint and type checks.
- `INTERVIEW_PREPARATION_GUIDE.md` marked as describing the legacy v0 system.

### Removed

- All legacy performance claims, retracted because of target leakage and related defects ([ADR-0002](docs/adr/0002-legacy-results-retracted.md)).
