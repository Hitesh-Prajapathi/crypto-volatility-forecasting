# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project aims to follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Package skeleton `src/volforecast` with shared contracts and a uv lockfile (foundation commit).
- `Makefile` with setup, lint, format, typecheck, test, coverage, data, stack and Helm targets.
- Pre-commit configuration (hygiene hooks, ruff, mypy, gitleaks, nbstripout) and `.editorconfig`.
- GitHub Actions CI (lint, typecheck, test with coverage, security, Helm validation) and Dependabot configuration.
- Documentation: `docs/architecture.md`, `docs/execution_plan.md`, and architecture decision records 0001-0007, 0009 and 0010.
- M1: Binance/Coinbase kline ingestion (`python -m volforecast.data ingest|quality`), Pandera schemas, Parquet store with content-hash manifest, missing-bar policy and grid snapping (ADR-0003), realized measures (RV, bipower variation, jumps, semivariances) and HAR features.
- M2: baseline models (naive, EWMA, GARCH, GJR-GARCH, HAR family), expanding walk-forward engine, loss and statistical tests (QLIKE, Diebold-Mariano, Mincer-Zarnowitz, MCS), backtest pipeline and report (`python -m volforecast backtest|report`, `make backtest`, `make report`) and a regression gate.
- M3: LightGBM and XGBoost challengers, equal and inverse-loss ensembles, calendar-aware HAR-DoW / log-HAR-DoW benchmarks; `log_har_dow` reported as a second benchmark (`report --benchmark2`).
- M4: VaR and ES backtests.
- M5: forecast store (SQLAlchemy, idempotent upserts), MLflow registry with `@champion`/`@challenger` aliases and a statistical promotion gate, Prefect flows (`ingest`, `forecast`, `evaluate`, `retrain`), PSI + Wasserstein drift and performance triggers, end-to-end daily-cycle test, `docs/mlops.md`.
- M6: `/v1` FastAPI service (forecast, history, models, backtest summary, readiness, metrics) with snapshot hot-reload, ETag, rate limiting and CORS allowlist; `docs/api.md`.
- Official walk-forward results for BTC, ETH and SOL in the README and `reports/tables.md`.
- M6: API and jobs container images and a Docker Compose local stack (API, MLflow, Prefect, MinIO, Postgres, Prometheus, Grafana).
- M7: Helm chart, kind bootstrap, Argo CD app-of-apps and the CD workflow (not yet run on a cluster).
- M8: Grafana dashboards, Prometheus alert rules, k6 load test.
- Documentation: `docs/platform.md`, `docs/runbook.md`, `docs/slo.md` and `docs/model_card.md`.
- LSTM challenger `lstm` (optional `dl` extra, CPU): log-target h-day RV forecaster on 22-66 day sequences of realized measures with a per-fit scaler, chronological early-stopping split and seeded determinism ([ADR-0012](docs/adr/0012-lstm-challenger.md)); evaluation config `configs/backtest_lstm.yaml`, not part of the default backtest.

### Changed

- `README.md` rewritten for the refinement phase, with a results section that is generated by `make report`.
- Legacy code moved to `legacy/` (tag `v0-legacy`) and excluded from lint and type checks.
- Notebooks moved to `legacy/notebooks/`.
- `ens_inv` excluded from production retrain candidates until its weights can be served.

### Removed

- `INTERVIEW_PREPARATION_GUIDE.md`, which described the retracted v0 system.
- All legacy performance claims, retracted because of target leakage and related defects ([ADR-0002](docs/adr/0002-legacy-results-retracted.md)).
